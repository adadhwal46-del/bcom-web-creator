# Student Portfolio Builder

Sample main Lovable prompt

“Create a responsive personal portfolio website for a first-year Bcom student. Include clearly navigable Home, About, Services/Features, and Contact sections. Use a modern academic-professional appearance, readable typography, subtle blue accents, generous whitespace, and a layout that works on desktop and mobile. The Home section should introduce the student with a concise headline and short profile summary. The About section should include education, interests, and career goals. The Services/Features section should show student capabilities such as business research, presentation design, basic data analysis, communication, and digital productivity. The Contact section should include an editable contact form or clearly marked contact details. Add a clear navigation bar, accessible contrast, consistent spacing, and simple interactions. Use placeholder student details that can be replaced before publishing. Do not claim that any feature is complete until it has been tested.”
